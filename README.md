# de-journey

Tracking my path from production support to data engineering: what I learn each day, the certifications I earn, and the projects I build.

## About me
- **Now:** Assistant System Engineer at TCS, in production support for a banking data integration platform
- **Background:** B.E. in Artificial Intelligence & Machine Learning
- **Goal:** Data Engineer role in 2027 (ETL Developer / Junior Data Engineer first, then bigger product companies)
- **Why data engineering:** Production support has shown me how a bank's data platform really runs: batch jobs, failed loads, reruns and reconciliation. I've seen what happens when pipelines break. Now I want to be on the other side, building pipelines that are reliable from the start.
